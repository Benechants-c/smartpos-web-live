Important production notes

  • This version stores data in one browser using localStorage. It does not synchronise across shops, devices or staff.
  • Do not store real passwords or rely on front-end role checks. Connect Firebase Auth and Firestore with strict security rules before live use.
  • ZIMRA fiscalisation requires an approved integration/device and cannot be activated by a visual ON switch alone.
